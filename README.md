# Weather Dashboard

A Python-based weather dashboard designed to retrieve, process, and visualise real-time weather information and forecast data through an interactive interface.

## Overview

The project aims to provide users with relevant weather insights for selected locations, including current temperature, humidity, wind speed, and forecast trends. It combines API integration, data processing, and visualisation to deliver an accessible weather monitoring application.

## Technology Stack

- **Python** – Core programming language
- **Requests** – API integration and HTTP requests
- **JSON** – Handling structured API responses
- **Pandas** – Data processing and manipulation
- **Plotly** – Interactive data visualisation
- **Streamlit** – Dashboard development
- **Open-Meteo API** – Weather and forecast data source

## Planned Features

- Location-based weather search
- Current weather information
- Hourly and daily weather forecasts
- Interactive temperature visualisations
- Weather metrics and statistical insights

## Installation and Setup

1. Clone the repository:

   git clone (https://github.com/prernadhar06-pixel/weather-dashboard)
   

2. Navigate to the project directory:

   cd weather-dashboard


3. Install the required dependencies:

   pip install -r requirements.txt


4. Run the application:

   streamlit run app.py
